# 00. Saber.GAS.RTS 总览与装配入口

`Saber.GAS.RTS` 的定位不是第二套战斗 Core，而是：

- 引用 `Saber.GAS`
- 为 RTS / MOBA / 阵营玩法提供默认接线
- 承载不适合放进纯 GAS Core 的实现

当前这层已经包含：

- `RtsTeamRelationResolver`
  - 基于 `TeamId` 的 RTS 默认阵营关系解析器
- `RtsCombatRuntimeModulePack`
  - RTS 默认装配入口
- `IRtsSpatialQueryService`
  - RTS 空间查询预留接口
- `IRtsVisibilityService`
  - RTS 视野 / 可见性预留接口
- `IRtsOrderRuleService`
  - RTS 指令校验预留接口

## 1. Core 与 RTS 的边界

放在 `Saber.GAS`：

- Actor / Ability / Effect / Trigger / Runtime 主链
- 快照、回滚、对象池、固定点、语义层
- 所有游戏类型都共用的抽象接口

放在 `Saber.GAS.RTS`：

- Team 阵营关系实现
- RTS 默认装配
- RTS 特有查询和规则扩展位

## 2. 推荐接线

最简单的 RTS 接线方式：

```csharp
var pack = new RtsCombatRuntimeModulePack();
var options = pack.CreateRuntimeOptions();
var runtime = new CombatRuntime(worldState, options);
```

这会默认接入：

- `RtsTeamRelationResolver`
- `DefaultCombatModeRules`
- `DefaultTargetingResolver`

## 3. 后续扩展建议

如果你后面要继续往 RTS / MOBA 扩：

- 视野、隐身、反隐
- 搜敌范围、警戒范围、Aoe 查询
- 下指令限制、建筑放置校验
- 中立野怪阵营、临时盟约、控制权切换

优先在 `Saber.GAS.RTS` 里补实现。

如果某能力被证明是各种 GAS 项目都会用到，再反向抽象回 `Saber.GAS`。
