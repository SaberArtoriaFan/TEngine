# 系统分层与核心对象

## 1. 分层

当前 `Saber.GAS` 可以按下面几层理解。

### 1.1 Foundation

职责：

- 标识符
- Tick
- 世界坐标
- 确定性随机

关键类型：

- `ActorId`
- `AbilityId`
- `EffectId`
- `AbilityInstanceId`
- `SimulationTick`
- `WorldPosition`
- `DeterministicRandom`

### 1.2 Tags / Attributes / Resources

职责：

- 角色状态表达
- 数值基础容器
- 资源消耗与回复

关键类型：

- `GameplayTag`
- `GameplayTagContainer`
- `AttributeSet`
- `AttributeValue`
- `ResourceSet`
- `ResourceValue`

### 1.3 Effects

职责：

- 效果定义
- 效果实例
- 持续时间
- 周期触发
- 叠层与刷新

关键类型：

- `EffectDefinition`
- `EffectSpec`
- `ActiveEffect`

### 1.4 Abilities

职责：

- 技能定义
- 激活请求
- 生命周期实例
- 执行记录

关键类型：

- `AbilityDefinition`
- `AbilityActivationRequest`
- `AbilityExecutionRecord`
- `ActiveAbilityInstance`

### 1.5 Runtime

职责：

- 世界状态
- 模式规则
- 目标解析
- 行动尝试与影响流水线
- Tick 推进

关键类型：

- `CombatWorldState`
- `CombatRuntime`
- `CombatActionAttempt`
- `ActionBlock`
- `CombatImpact`
- `CombatRuntimeOptions`

### 1.6 Networking

职责：

- 命令缓冲
- 命令历史
- 快照
- 恢复
- 重放

关键类型：

- `CombatSimulationHost`
- `CombatInputCommand`
- `CombatCommandResult`
- `CombatSnapshot`
- `CombatReplayReport`

## 2. 角色状态对象

`CombatActorState` 是当前逻辑层的核心实体。

它持有：

- 身份：`ActorId` / `TeamId`
- 坐标：`WorldPosition`
- 生死：`IsAlive`
- Tags：`GameplayTagContainer`
- Attributes：`AttributeSet`
- Resources：`ResourceSet`
- Granted Abilities：能力授权列表
- Active Effects：持续效果列表
- Active Ability Instances：长期技能实例列表
- Cooldowns：按 `AbilityId` 管理的结束 Tick

这基本就是新框架里的“仿真角色内核”。

## 3. 数值边界

当前主数值统一使用项目现有 `FixedPoint` 程序集中的 `Herta.FP`。

这样做的目的不是单纯替换类型，而是为了把下面这些地方统一拉回确定性边界：

- 属性值
- 资源值
- 技能范围
- 位置
- 资源变化
- 效果强度

这也是后续网络同步、服务器权威、重放和纠正的基础前提。
