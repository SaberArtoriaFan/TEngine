# 验收清单

## 1. 程序集与边界

- `Saber.GAS` 是否是独立程序集
- 是否未引用旧 `FFD.Battle` / `NewBattle` 运行时
- 是否主逻辑不依赖 Unity 表现对象

## 2. 数值与确定性

- 属性、资源、范围、位置是否基于 `Herta.FP`
- `Saber.GAS/Runtime` 下是否没有 `float / double` 作为战斗主数值
- 是否存在确定性 Tick 推进

## 3. 行动链

- 是否存在 `CombatActionAttempt`
- 是否存在 `ActionBlock`
- 是否存在 `CombatImpact`
- 是否支持先生成 impact 再 resolve

## 4. 生命周期

- 是否支持 `Instant`
- 是否支持 `Cast`
- 是否支持 `Channeled`
- 是否支持 `Passive`
- 是否支持周期与结束阶段
- 是否支持主动取消

## 5. 效果层

- 是否支持持续效果
- 是否支持叠层
- 是否支持周期效果
- 是否支持净化 / 移除 effect
- 是否支持 Tag 授予与撤销

## 6. 网络层

- 是否有命令队列
- 是否有命令历史
- 是否有快照仓库
- 是否能恢复快照
- 是否能重放后续命令
- 是否通过接口留出深拷贝实现

## 7. 文档

- 是否有总览文档
- 是否有行动管线文档
- 是否有网络宿主文档
- 是否有旧框架迁移映射文档
- 是否有 FastCloner 接入说明
