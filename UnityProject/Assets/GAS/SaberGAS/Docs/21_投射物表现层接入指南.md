# Saber.GAS 投射物表现层接入指南

## 1. 这份文档解决什么问题

本指南专门补齐以下链路：

1. 逻辑层如何产生日志级事件（Spawn/Hit/Expired）
2. Unity 表现层如何订阅事件并驱动模型、动画、特效、音频
3. 如何调节投射物速度、角度、寿命并和表现保持一致
4. 如何管理投射物资源生命周期，避免泄漏和错位

## 2. 先理解当前能力边界

当前 Runtime 投射物是“逻辑实体”，不是 Unity `GameObject`。  
表现层需要自行映射逻辑实体到可视对象。

- 逻辑追踪模式：
  - `FixedPoint`：朝固定目标点飞行
  - `TrackActor`：逐 Tick 追踪目标 Actor（目标丢失会过期）
- 逻辑飞行轨迹：直线匀速推进（无重力抛物线）
- 命中判定：距离判定（`HitRadius`）
- 事件类型：`ProjectileSpawned`、`ProjectileHit`、`ProjectileExpired`

## 3. 配置链路（Authoring -> Runtime -> Event -> View）

### 3.1 Authoring（Effect 里配置投射物）

在 `EffectDefinitionAsset` 中添加 `EffectProjectilePayloadModule`，每个投射物项配置：

- `TrackingMode`
- `SpeedPerTick`
- `HitRadius`
- `MaxLifetimeTicks`
- `ImpactTags`（推荐补一个视觉路由 Tag）
- `ImpactOperations`（命中后执行）

建议额外约定一个视觉 Tag，例如：

- `projectile.visual.firebolt`
- `projectile.visual.ice_shard`

这样表现层可按 Tag 映射到不同 Prefab，不依赖硬编码 Effect 名称。

### 3.2 Runtime（逻辑执行）

`SpawnProjectile` 会创建 `CombatProjectileState` 并加入 `CombatWorldState.Projectiles`。  
每 Tick 由 `CombatProjectileModule.OnTick` 推进。  
命中和过期后实体会从世界状态移除并回收对象池。

### 3.3 Event（桥接信号）

通过 `ICombatEventSink` 收到事件：

- `ProjectileSpawned`：消息体 `Message` 是 `ProjectileInstanceId` 字符串
- `ProjectileHit`：消息体同样是 `ProjectileInstanceId`
- `ProjectileExpired`：消息体同样是 `ProjectileInstanceId`

注意：`Hit/Expired` 触发时，逻辑实体已被移除，表现层应使用自己缓存的绑定数据做收尾，不要再依赖 WorldState 查询。

### 3.4 View（Unity 表现层）

表现层建议维护 `ProjectileInstanceId -> ViewBinding` 的字典：

- Spawn：创建可视对象，播放出手动画/VFX
- Update：读取逻辑位置同步 Transform，按速度更新 Animator 参数
- Hit：播放命中动画/VFX/SFX，延时回收对象
- Expired：播放消散动画/VFX，延时回收对象

## 4. 参数调节：速度、角度、寿命

## 4.1 速度（必调）

- 逻辑速度字段：`SpeedPerTick`
- 估算飞行 Tick：`travelTicks ~= ceil(distance / SpeedPerTick)`
- 建议寿命：`MaxLifetimeTicks >= travelTicks + 安全缓冲`

若你的仿真频率是 `TickRate`（例如 30）：

- 近似“每秒速度” = `SpeedPerTick * TickRate`

## 4.2 角度（当前版本的可调方式）

当前没有独立“发射仰角”字段，角度来自“起点到目标点方向”。

- `FixedPoint`：由 `sourcePosition -> targetPoint` 决定方向
- `TrackActor`：由 `sourcePosition -> targetActor.position` 动态决定方向

想调“发射角度”，建议：

1. 在施法请求里调整 `targetPoint`（推荐）
2. 调整发射点（例如枪口/手部）在逻辑坐标中的位置
3. 仅在表现层做抛物线视觉（逻辑仍保持直线，命中以 Runtime 为准）

提示：如果你做“纯视觉抛物线”，命中时机必须跟随 Runtime 事件，不要让动画倒推逻辑。

## 5. 模型、动画、特效配置建议

每个投射物 Prefab 建议结构：

- 根节点：`ProjectileRoot`
- 模型节点：`Mesh`（静态网格或 SkinnedMesh）
- 动画器：`Animator`（关闭 Root Motion）
- 特效节点：`TrailRenderer` / `ParticleSystem`
- 可选：`AudioSource`

Animator 参数建议统一：

- Trigger：`Spawn`
- Trigger：`Hit`
- Trigger：`Expire`
- Float：`Speed`

典型状态机：

- `Spawn` -> `FlyLoop` -> (`Hit` 或 `Expire`)

## 6. 事件桥接代码骨架（可直接改造成项目脚本）

```csharp
using System;
using System.Collections.Generic;
using Cysharp.Threading.Tasks;
using Saber.GAS.Foundation;
using Saber.GAS.Networking;
using Saber.GAS.Projectiles;
using Saber.GAS.Runtime;
using UnityEngine;

public sealed class ProjectilePresentationBridge : MonoBehaviour, ICombatEventSink
{
    [Serializable]
    private struct VisualRule
    {
        public string RequiredTag;
        public string PrefabLocation;
    }

    private sealed class ViewBinding
    {
        public ProjectileInstanceId Id;
        public GameObject View;
        public Animator Animator;
        public string PrefabLocation;
        public WorldPosition LastLogicPosition;
    }

    [SerializeField] private string _defaultProjectilePrefab = "Regicide/VFX/Projectile_Default";
    [SerializeField] private VisualRule[] _rules = Array.Empty<VisualRule>();

    private readonly Dictionary<ProjectileInstanceId, ViewBinding> _bindings = new();
    private CombatSimulationHost _host;

    public void Initialize(CombatSimulationHost host)
    {
        _host = host;
    }

    public void Publish(CombatEvent combatEvent)
    {
        if (_host == null || combatEvent == null)
        {
            return;
        }

        if (!TryParseProjectileId(combatEvent.Message, out var projectileId))
        {
            return;
        }

        switch (combatEvent.Kind)
        {
            case CombatEventKind.ProjectileSpawned:
                HandleSpawnAsync(projectileId).Forget();
                break;
            case CombatEventKind.ProjectileHit:
                HandleHit(projectileId);
                break;
            case CombatEventKind.ProjectileExpired:
                HandleExpire(projectileId);
                break;
        }
    }

    private async UniTaskVoid HandleSpawnAsync(ProjectileInstanceId projectileId)
    {
        var state = TryFindProjectile(projectileId);
        if (state == null || _bindings.ContainsKey(projectileId))
        {
            return;
        }

        var prefabLocation = ResolvePrefabLocation(state);
        var go = await GameModule.Resource.LoadGameObjectAsync(prefabLocation, transform, this.GetCancellationTokenOnDestroy());
        if (go == null)
        {
            return;
        }

        go.transform.position = ToUnity(state.Position);
        var binding = new ViewBinding
        {
            Id = projectileId,
            View = go,
            Animator = go.GetComponent<Animator>(),
            PrefabLocation = prefabLocation,
            LastLogicPosition = state.Position,
        };
        binding.Animator?.SetTrigger("Spawn");
        _bindings[projectileId] = binding;
    }

    private void LateUpdate()
    {
        if (_host == null || _bindings.Count == 0)
        {
            return;
        }

        foreach (var pair in _bindings)
        {
            var binding = pair.Value;
            var state = TryFindProjectile(binding.Id);
            if (binding.View == null || state == null)
            {
                continue;
            }

            var pos = ToUnity(state.Position);
            var prev = ToUnity(binding.LastLogicPosition);
            var dir = pos - prev;
            binding.View.transform.position = pos;
            if (dir.sqrMagnitude > 0.0001f)
            {
                binding.View.transform.rotation = Quaternion.LookRotation(dir.normalized, Vector3.up);
            }

            binding.Animator?.SetFloat("Speed", (float)state.SpeedPerTick);
            binding.LastLogicPosition = state.Position;
        }
    }

    private void HandleHit(ProjectileInstanceId projectileId)
    {
        if (!_bindings.TryGetValue(projectileId, out var binding))
        {
            return;
        }

        binding.Animator?.SetTrigger("Hit");
        RecycleLater(binding).Forget();
        _bindings.Remove(projectileId);
    }

    private void HandleExpire(ProjectileInstanceId projectileId)
    {
        if (!_bindings.TryGetValue(projectileId, out var binding))
        {
            return;
        }

        binding.Animator?.SetTrigger("Expire");
        RecycleLater(binding).Forget();
        _bindings.Remove(projectileId);
    }

    private async UniTaskVoid RecycleLater(ViewBinding binding)
    {
        await UniTask.DelayFrame(2);
        if (binding?.View != null)
        {
            Destroy(binding.View);
        }
    }

    private string ResolvePrefabLocation(CombatProjectileState state)
    {
        foreach (var rule in _rules)
        {
            if (!string.IsNullOrWhiteSpace(rule.RequiredTag) &&
                state.ImpactTags != null &&
                state.ImpactTags.Contains(new Saber.GAS.Tags.GameplayTag(rule.RequiredTag)))
            {
                return string.IsNullOrWhiteSpace(rule.PrefabLocation) ? _defaultProjectilePrefab : rule.PrefabLocation;
            }
        }

        return _defaultProjectilePrefab;
    }

    private CombatProjectileState TryFindProjectile(ProjectileInstanceId projectileId)
    {
        foreach (var projectile in _host.Runtime.WorldState.Projectiles)
        {
            if (projectile != null && projectile.InstanceId == projectileId)
            {
                return projectile;
            }
        }

        return null;
    }

    private static bool TryParseProjectileId(string message, out ProjectileInstanceId id)
    {
        if (long.TryParse(message, out var value) && value > 0)
        {
            id = new ProjectileInstanceId(value);
            return true;
        }

        id = ProjectileInstanceId.Empty;
        return false;
    }

    private static Vector3 ToUnity(WorldPosition p)
    {
        return new Vector3(p.X.AsFloat, p.Y.AsFloat, p.Z.AsFloat);
    }
}
```

说明：

- 这个骨架强调“逻辑权威、表现跟随”，并展示了完整事件链闭环。
- 示例里 `Destroy` 仅作为最简示意。若你使用对象池，请替换为池回收。
- 资源加载使用 `GameModule.Resource.LoadGameObjectAsync`，遵循 TEngine 异步规范。

## 7. 链路补齐自检清单

上线前建议逐项检查：

1. Effect 是否通过 `EffectProjectilePayloadModule` 配置（而非手写 `SpawnProjectile`）
2. `SpeedPerTick`、`MaxLifetimeTicks`、`HitRadius` 是否有明确调参基线
3. 是否实现 `ICombatEventSink` 并接入 `CombatRuntimeOptions.EventSink`
4. 是否建立 `ProjectileInstanceId -> ViewBinding` 映射
5. 是否区分 `Hit` 与 `Expire` 两种收尾表现
6. 是否对资源做成对管理（加载/销毁或池化归还）
7. 是否在回放/快照恢复后可继续正确显示在飞投射物

## 8. 后续可扩展方向

- 增加“发射角/偏移”Authoring 字段，避免角度完全依赖目标点
- 引入 AoE/碰撞查询后补充爆炸弹、穿透弹、弹跳弹
- 将 `ProjectileSpawned` 的消息体扩展为结构化 payload（减少二次查询）
