# Saber.GAS 投射物飞行系统说明

## 1. 目标

本次实现提供一版可快照、可回滚、可重放的确定性投射物运行时能力，覆盖以下主链路：

- Effect 侧通过 `ImpactOperations` 触发 `SpawnProjectile`
- Runtime 在 `CombatWorldState` 中创建并维护投射物实体
- 每个 Tick 推进投射物飞行
- 命中后复用既有 `Effect -> Impact -> Resolve` 结算链
- 过期或目标失效时安全移除，不应用命中载荷

## 2. 当前支持范围

- 追踪模式：
  - `FixedPoint`（固定目标点）
  - `TrackActor`（追踪 Actor）
- 生命周期：
  - 生成（`ProjectileSpawned`）
  - 命中（`ProjectileHit`）
  - 过期（`ProjectileExpired`）
- 命中载荷：
  - 通过 `CombatImpactOperation` 列表执行
  - 支持继续触发资源结算、效果施加、语义模块与 Trigger

## 3. Authoring 约束

- 推荐通过 `EffectProjectilePayloadModule` 配置投射物参数。
- `CombatImpactOperationAuthoringData` 不允许直接构建 `SpawnProjectile`，会提示改用模块化入口。
- 当投射物关键字段非法（如速度、小于等于 0 的生存 Tick）时，构建与校验会明确报错。

## 4. 快照与回滚

- `CombatWorldState` 新增投射物集合与实例 Id 递增计数。
- `FastClonerDeepCloneProvider` 深拷贝投射物定义与运行时状态，保证回滚后飞行进度一致。
- 对象池新增 `CombatProjectileState`，降低频繁生成/销毁的 GC 压力。

## 5. 已知边界

本次不包含以下能力（后续可扩展）：

- AoE 检索、扇形/范围目标查询
- 地形阻挡、复杂碰撞体扫描
- 反弹、穿透、分裂、多段弹道
- 独立 Projectile 资产类型（当前仍挂在 Effect 模块下）

## 6. 扩展建议

- 在 Query 服务就绪后，优先补 AoE 与碰撞查询。
- 在表现层订阅 `ProjectileSpawned/Hit/Expired`，统一驱动特效、音频和镜头反馈。
- 将 Area / Aura / Thinker 的延迟命中能力复用到统一 `ImpactOperations` 数据契约。
