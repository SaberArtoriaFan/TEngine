# 行动管线与能力生命周期

## 1. 行动管线

当前运行时不再是“校验通过后直接改状态”，而是分成了四层：

1. `AbilityActivationRequest`
2. `CombatActionAttempt`
3. `CombatImpact`
4. `ResolveBuiltInImpact / Custom Resolver`

这就是从旧框架迁来的核心思想：

- `BlockAttempt`
- `AttemptImpact`

## 2. Attempt

`CombatActionAttempt` 代表“一次技能尝试”。

它包含：

- 请求本身
- 来源角色
- 技能定义
- 执行上下文
- 当前阶段
- 解析后的目标
- 阻断列表
- 待应用 impact 列表

如果 `Blocks.Count > 0`，这次尝试就视为失败。

## 3. Block

`ActionBlock` 不再只是一个布尔失败，而是结构化的阻断原因。

当前内建了这些分类：

- `InvalidRequest`
- `SourceState`
- `AbilityState`
- `Cost`
- `Cooldown`
- `Targeting`
- `Lifecycle`
- `ModeRule`
- `Custom`

这意味着后续无论你做：

- 回合制行动点限制
- MOBA 沉默 / 禁锢
- RTS 建造条件限制

都可以统一落到同一种阻断结构里。

## 4. Impact

`CombatImpact` 是最终落地前的影响包。

每个 impact 包含：

- 来源 Actor
- 目标 Actor
- 来源 Ability
- 来源 Effect
- 创建 Tick
- 当前阶段
- 一组 `CombatImpactOperation`

当前内建 operation 类型：

- `ResourceDelta`
- `ApplyEffect`
- `RemoveEffectsByTag`
- `RemoveEffectById`
- `Cue`

因此运行时现在已经支持：

- 先净化再上效果
- 先生效即时资源变化，再挂持续效果
- 通过 resolver 扩展新的影响解释方式

## 5. 生命周期

当前 `AbilityDefinition` 已经支持长期技能所需的基础字段：

- `CastDurationTicks`
- `ActiveDurationTicks`
- `IntervalTicks`
- `Effects`
- `PeriodicEffects`
- `EndEffects`
- `ExecuteEffectsOnActivate`
- `CancelOnSourceDeath`
- `AutoActivatePassive`

## 6. ActiveAbilityInstance

`ActiveAbilityInstance` 是长期技能实例。

它持有：

- 实例 ID
- 来源 Actor
- Ability 定义
- 锁定目标数据
- 创建 Tick
- Resolve Tick
- 激活 Tick
- 下次周期 Tick
- 结束 Tick
- 当前状态

状态包括：

- `Casting`
- `Active`
- `Completed`
- `Cancelled`

## 7. Tick 时会发生什么

`CombatRuntime.Tick()` 当前会做：

1. 推进世界 Tick
2. 自动确保被动技能实例存在
3. 角色资源回复
4. 处理长期技能实例
5. 处理持续效果
6. 调用模式规则的 `OnPostTick`

### 7.1 技能实例处理

当技能实例进入 `Active` 时，会：

- 授予 `GrantedTagsWhileActive`
- 根据配置执行激活阶段 Effects

当技能实例处于持续状态时，会：

- 按 `IntervalTicks` 触发 `PeriodicEffects`

当技能实例完成或取消时，会：

- 执行 `EndEffects`
- 撤销活动期间授予的 Tag

## 8. 与旧 NewBattle 的概念映射

- `ActionRuntimeSituation`
  -> `CombatActionAttempt + AbilityExecutionContext`
- `BlockAttempt`
  -> `CombatActionAttempt.Blocks`
- `AttemptImpact`
  -> `CombatImpact`
- `BuffInstance`
  -> `ActiveEffect`
- `ActionEvent` 的长期执行部分
  -> `ActiveAbilityInstance`
